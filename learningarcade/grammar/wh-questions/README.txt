WH QUESTION CHALLENGE

This version uses the 12 picture panels supplied for the game.

Game flow:
1. Look at the picture.
2. Click the scrambled words to build the WH-question.
3. Check the question.
4. Type a complete answer from the picture.
5. Submit.
6. If correct, the game automatically moves to the next round.

No completed question is shown before the student unscrambles it.

Images are stored in the images/ folder.
