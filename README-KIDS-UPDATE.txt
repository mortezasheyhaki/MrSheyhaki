MrSheyhaki.ir — Kids & Teens / Teacher Select update
====================================================

HOW TO INSTALL
1. Unzip this archive.
2. Copy the "learningarcade" folder into your site root,
   merging with the existing learningarcade folder.
3. Especially overwrite:
   - learningarcade/theme.js
   - learningarcade/index.html   (Kids & Teens → select-teacher)
   - learningarcade/style.css    (optional: button hover shine)
   - learningarcade/kids/        (entire folder)

WHAT'S INCLUDED
- Teacher Select page (futuristic dark theme + light mode)
- Ms. Moonlight Starlight Forest world
  - Courtyard background (embedded)
  - Large grounded character + activity panel
  - WebP-optimized character images
  - Hover shine on buttons
  - Theme toggle (no floating profile icon)
- Activity placeholders: Play, Learn, Speak, Write, Listen, Read
- Kids hub redirects straight to Teacher Select
- Arcade "Kids & Teens" links to kids/select-teacher/
