# Opposite Snap

This is a standalone HTML, CSS, and JavaScript game designed for VS Code **Live Server**. Open the `opposite-snap-game` folder in Visual Studio Code, right-click `index.html`, and choose **Open with Live Server**.

The game practices all eight opposite pairs from the unit: **big/small**, **old/new**, **fast/slow**, **beautiful/ugly**, **cheap/expensive**, **long/short**, **clean/dirty**, and **easy/difficult**. Each round requires one large-tap answer, provides immediate correction, awards score and streak points for correct choices, and ends with icon-only back and replay controls.

The interface includes sixteen local image panels cropped from the supplied adjective sheet: each round opens with the target photo and reveals its paired opposite photo after the learner chooses. It has no external dependencies and is designed for phone screens with a 390px mobile layout, large answer cards, and reduced-motion support.
