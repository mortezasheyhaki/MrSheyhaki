Teen2Teen 1 · Unit 10 · Games pack
==================================

How to install (copy into your site root, same paths):

1) course-data.js
   → paste/replace at the site root (next to index.html)

2) resources/teen-2-teen/1/unit-10/games/
   → copy the whole "games" folder contents into:
      resources/teen-2-teen/1/unit-10/games/

   Includes:
   - index.html                  (games list page — 4 cards)
   - clothes-flashcards/
   - clothes-match/
   - clothes-sound-match-picture/
   - clothes-bingo/

Hard-refresh the browser after uploading (Ctrl+Shift+R).

Games on the list page:
  • Clothes Flashcards   (Vocabulary)
  • Clothes Match        (Vocabulary)
  • Sound Match Picture  (Listening)
  • Clothes Bingo        (Listening)
