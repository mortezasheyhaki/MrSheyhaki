INSTALL INSTRUCTIONS
====================

1. Copy the folder "match-classroom-objects" into:
   resources/american-english-file/starter/practical-english-1/games/

2. Replace the existing course-data.js with the one in this package:
   resources/american-english-file/assets/course-data.js

   (Or just add the new line if you prefer not to overwrite the whole file)

3. Done. The game will appear under Starter → Practical English 1 → Games.
